A2UIComponentScope

@Stable
class A2UIComponentScope

One component of a surface as its renderer sees it: its properties, resolved against the surface's data, its children, and what it does when the person uses it.

Values are plain Kotlin values: maps, lists, strings, numbers (Long or Double), booleans and null. A value the agent bound to the data model reads the data model now, and the surface draws again when the data changes.

Read it while composing, on the main thread.
