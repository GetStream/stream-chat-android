A2UICatalog

@Immutable
class A2UICatalog(val renderers: Map<String, A2UIComponentRenderer>)

How each component type of a surface looks, by type, such as Text.

Basic draws every component of the A2UI 1.0 basic catalog. Start from it to draw a type your own way; the agent still writes the type as the catalog describes it:

val catalog = A2UICatalog.Basic.with("Card") { scope ->
    BrandCard(modifier = scope.modifier) { scope.child()?.let { scope.Child(it) } }
}
Content copied to clipboard

To keep the agent from using a type, remove it with removing. The agent is told about the basic catalog's types the catalog draws, and a type the catalog has no renderer for shows nothing.
