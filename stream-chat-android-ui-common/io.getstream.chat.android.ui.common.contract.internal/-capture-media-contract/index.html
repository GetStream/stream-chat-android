CaptureMediaContract

class CaptureMediaContract(mode: CaptureMediaContract.Mode, fileManager: StreamFileManager = StreamFileManager(), pictureFile: File? = null, videoFile: File? = null, uriProvider: ShareableUriProvider = ShareableUriProvider()) : ActivityResultContract<CaptureMediaContract.Target, File?>

Activity result contract for capturing a photo or a video with a camera app.

The caller lists the camera apps available for the Mode with targets, lets the user pick one when there are several, and launches the contract with the picked Target. Capture intents are launched directly rather than through Intent.createChooser: the Android 16 share sheet crashes the system process when a target without a MIME type is picked.

Files are created in external storage directories:

  • Photos: {externalFilesDir}/Pictures/

  • Videos: {externalFilesDir}/Movies/ With fallback to cache directories if external storage is unavailable.

After createIntent the caller should persist pictureFile and videoFile paths so they can be restored after process death via the constructor.
