ScheduledMessage

@Immutable
data class ScheduledMessage(val id: String, val cid: String, val channel: ChannelInfo?, val message: Message, val scheduledAt: Date, val status: ScheduledMessageStatus, val failure: ScheduledMessageFailure?, val createdAt: Date, val updatedAt: Date)

A message of the current user that the server sends to a channel at scheduledAt. Until it is sent, it can be edited, rescheduled, sent right away or deleted.

message
Link copied to clipboard
val message: Message

The content that will be sent. It is not in the messages of the channel until it is sent, and has no reactions, replies or read state. Its Message.createdAt is scheduledAt, so it can be shown like any other message, and its Message.updatedAt is the one of the scheduled message. The mentioned users and groups, the quoted message and the poll come as IDs only: in Message.mentionedUsersIds, Message.mentionedGroups (without names), Message.replyMessageId and the poll_id of Message.extraData.
