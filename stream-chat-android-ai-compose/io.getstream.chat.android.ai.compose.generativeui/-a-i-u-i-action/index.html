AIUIAction

data class AIUIAction(val messageId: String, val format: AIUIFormat, val name: String, val label: String, val payload: Map<String, Any?> = emptyMap())

What a person did in a reply's generated UI that the agent should hear about, such as tapping a place or submitting a form.

Send it as their next message: label is its text, what people read in the conversation, and customData holds the action for the agent.

channel.sendMessage(Message(text = action.label, extraData = action.customData))
