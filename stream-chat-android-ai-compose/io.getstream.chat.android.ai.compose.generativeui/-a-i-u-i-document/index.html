AIUIDocument

data class AIUIDocument(val format: AIUIFormat, val version: String? = null, val isStreaming: Boolean = false, val content: Any?)

The UI a reply shows in place of its text, which the agent wrote in a format such as OpenUI.

The agent's backend writes it in the reply's ai_ui custom field. The reply's text stays readable on its own, for wherever the UI can't show, such as a push notification or an app without a renderer for the format:

"ai_ui": { "v": 1, "format": "openui", "status": "streaming", "content": "root = Card([title])" }
