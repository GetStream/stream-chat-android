AIUIEngine

interface AIUIEngine

Shows the documents of one renderer in one conversation. The host makes one per renderer and keeps it while it is kept, so an engine can hold each reply's state, and a format whose later replies change an earlier one's UI can follow the conversation.

The host calls it on the main thread.

open fun receive(document: AIUIDocument, messageId: String)

Takes a reply's document as it arrives or changes, oldest reply first, whether or not the reply is on screen, so a format whose later replies change an earlier one's UI can follow them all. It comes while the conversation composes, before any reply's content is asked for: keep what is on screen in snapshot state so it follows. Nothing by default.
