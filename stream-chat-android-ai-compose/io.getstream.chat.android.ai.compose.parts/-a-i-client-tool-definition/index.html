AIClientToolDefinition

data class AIClientToolDefinition(val name: String, val description: String = "", val inputSchema: Map<String, Any?>? = null, val isReadOnly: Boolean = false)

The name, description, argument schema and read-only hint of a client tool, as the agent sees them.

It reads and writes the same JSON as a Model Context Protocol tool (name, description, inputSchema and the readOnlyHint of its annotations), so a renderer can put it into the model's instructions as it is, and a tool described for MCP converts with fromJson:

{
  "name": "calendar",
  "description": "The person's events on a day.",
  "inputSchema": { "type": "object", "properties": { "day": { "type": "string" } }, "required": ["day"] },
  "annotations": { "readOnlyHint": true }
}
