Each message the person sends starts a turn: that message and the replies after it. The latest turn is at least as tall as the list, so when the person sends a message, the list scrolls it to the top and the reply grows below it without moving anything on screen. A conversation that loads, or replaces the one shown, opens at its end, and a button brings the end back into view whenever it is out of it.

Place the composer below the list, so the list knows how much of it is visible.

Parameters

messages

The conversation, oldest message first.

key

A stable, unique key for a message. A turn is known by its first message's key, so what is on screen stays in place as messages come and go around it. The key must be saveable in a Bundle, as with any lazy list key.

isFromUser

Whether the person using the app sent a message. Each of their messages starts a turn.

modifier

The modifier to apply to the list.

isThinking

Whether the agent is answering the latest message and its reply shows nothing yet. Meanwhile the latest turn ends with AIThinking.

loadOlderMessages

Loads the messages before the first one, which the list asks for as the person scrolls to its start. It shows a spinner meanwhile, and what is on screen stays in place as they arrive: the message that was first keeps starting a turn, even when the person's message before it arrives. Pass null once there are none left.

footer

Content under the latest turn's messages, such as what the agent is doing, or an error with a way to retry.

emptyContent

What the list shows while there are no messages, centered in it.

colors

The palette of the list's own views: the button that brings the end back into view, and the spinner while older messages load.

icons

The icons of the list's own views.

messageContent

The view of a message.

Shows AIMessages with the views of LocalChatAiComponentFactory: each message the person sent with ChatAiComponentFactory.AIConversationUserMessage, each reply with ChatAiComponentFactory.AIConversationAssistantMessage, and under a finished reply, once its answer is written out, ChatAiComponentFactory.AIConversationReplyActions.

A reply joins the list once it shows something; until then the list shows the agent thinking.

Parameters

messages

The conversation, oldest message first.

modifier

The modifier to apply.

pendingMessage

A message the person sent that is not in messages yet. Keep passing it until its reply starts: the list stops showing it once its copy arrives.

isThinking

Whether the agent is answering the latest message and its reply shows nothing yet. The list also knows it is while pendingMessage waits, and while the latest reply is being written but shows nothing.

approver

Who answers tool calls' questions on this device, to ask them.

loadOlderMessages

Loads the messages before the first one, which the list asks for as the person scrolls to its start. It shows a spinner meanwhile, and what is on screen stays in place as they arrive. Pass null once there are none left.

footer

A view under the latest turn's messages, such as what the agent is doing, or an error with a way to retry.

emptyContent

What the list shows while there are no messages, centered in it.

colors

The palette of the list's own views: the button that brings the end back into view, and the spinner while older messages load.

icons

The icons of the list's own views.
