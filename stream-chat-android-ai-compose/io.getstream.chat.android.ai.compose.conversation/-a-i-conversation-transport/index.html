AIConversationTransport

interface AIConversationTransport<M : AIMessage>

How an AIConversationState reaches the agent and learns what it holds: it sends what the person asks, stops the agent, and tells the state its messages as they change.

With Stream Chat, the conversation is a channel: the transport follows its messages and AI indicator events, and sends each request through the channel or your agent's own API.

class AgentTransport(
    private val channel: ChannelState,
    private val agent: AgentApi,
    private val scope: CoroutineScope,
) : AIConversationTransport<AgentMessage> {

    override fun connect(feed: AIConversationFeed<AgentMessage>) {
        scope.launch {
            channel.messages.collect { messages -> feed.update(messages = messages.map(::AgentMessage)) }
        }
    }

    override suspend fun send(request: AIConversationRequest<AgentMessage>) {
        agent.respond(request.text, files = request.attachments)
    }

    override suspend fun stop() {
        agent.interrupt()
    }
}

abstract suspend fun send(request: AIConversationRequest<M>)

Sends what the person asks. Return once the agent has the request: its reply arrives through the feed. A thrown exception shows as the state's error, and the person can retry, which sends the same request again with the same AIConversationRequest.messageId: if the first attempt reached your backend, or you keep a copy of the failed message, use the id so the message isn't added twice.
